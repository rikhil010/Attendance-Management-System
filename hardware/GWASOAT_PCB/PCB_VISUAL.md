### CROSS-SECTION (Layer Stackup)

```
         ┌─────────────────────────────────────────────┐
         │          F.SilkS (White text/labels)        │
         ├─────────────────────────────────────────────┤
         │          F.Mask (Green solder mask)         │
         ├═════════════════════════════════════════════╡
  35µm → ║  F.Cu — Signal traces + Power (0.3/0.5mm)  ║ ← Copper
         ├═════════════════════════════════════════════╡
         │                                             │
 1.51mm  │          FR4 Core (εr = 4.5)               │ ← Dielectric
         │                                             │
         ├═════════════════════════════════════════════╡
  35µm → ║  B.Cu — Solid GND Pour (ground plane)      ║ ← Copper
         ├═════════════════════════════════════════════╡
         │          B.Mask (Green solder mask)         │
         └─────────────────────────────────────────────┘
         
         Total thickness: ~1.6mm
```

```
                    +3V3 RAIL (0.5mm trace)
    ═══════════════════════════════════════════════════════
         │         │         │         │         │
         │         │         │         │         │
       ┌─┴─┐    ┌─┴─┐    ┌─┴─┐    ┌─┴─┐    ┌─┴─┐
       │C2 │    │C3 │    │J3 │    │J4 │    │J2 │
       │   │    │   │    │VCC│    │VCC│    │VCC│
       └─┬─┘    └─┬─┘    └─┬─┘    └─┬─┘    └─┬─┘

         ▼ GND    ▼ GND    ▼ GND    ▼ GND    ▼ GND
    ─ ─ ─ ─ ─ ─(via)─ ─ ─(via)─ ─ ─(via)─ ─ ─(via)─ ─ ─
                    B.Cu GND PLANE (solid pour)


    I2C Bus (0.3mm traces):
    ESP32 GPIO21 ──────────────────────► J3 pin 3 (SDA)
    ESP32 GPIO22 ──────────────────────► J3 pin 4 (SCL)

    UART Bus (0.3mm traces):
    ESP32 GPIO16 ◄────────────────────── J4 pin 3 (FP TX)
    ESP32 GPIO17 ──────────────────────► J4 pin 4 (FP RX)
    ESP32 GPIO4  ◄────────────────────── J4 pin 5 (TOUCH)

    SPI Bus (0.3mm traces, matched length):
    ESP32 GPIO19 ◄────────────────────── J2 pin 3 (MISO)
    ESP32 GPIO23 ──────────────────────► J2 pin 4 (MOSI)
    ESP32 GPIO18 ──────────────────────► J2 pin 5 (SCK)
    ESP32 GPIO5  ──────────────────────► J2 pin 6 (CS)
```
